// 05 — Personal AI
AI

I Built My Own
AI Assistant

J.A.R.V.I.S. is a low-latency, privacy-focused voice assistant I built to run as a Linux system daemon on my own hardware — no cloud, no API key, no data leaving my machine.

Using Ollama for local language model orchestration and small language model (SLM) inference, I architected a full voice pipeline with wake word detection, real-time speech processing, and response generation — all running locally with systemd service management.

This isn't a wrapper around ChatGPT. It's a from-scratch local AI system — which means I understand what's happening at every layer of the stack. That's the kind of AI thinking I want to bring into engineering environments.
